# Оценка точности AI-агента

Дата: 23.10.2026 05:11.

**Методика.** Эталон каждого вопроса — отдельный SQL к базовым таблицам (eval/cases*.py), написанный независимо от инструментов агента. Точность фактов — доля эталонных фактов, верно приведённых в ответе: ID, БИН, номера и даты — дословно; количества — точно; суммы — ±1 тг; цены — ±0.01; проценты — ±0.1. Отдельная проверка «нет выдуманных фактов»: каждая ячейка таблицы Top-K (ID договора, №, дата, БИН заказчика) сверяется с core.contract, каждый БИН в тексте — с core.subject. Отложенная выборка — вопросы, которые не использовались при разработке агента; её результат до доработки агента сохранён в истории ниже.
